# 🚀 UPI-Shiksha  
### Learn UPI Payments — Risk-Free 💸

UPI-Shiksha is a digital payment learning platform designed to help beginners understand and practice UPI transactions in a safe, simulated environment using virtual coins.

---

## 📱 About the Project

UPI-Shiksha provides users with a hands-on experience of digital payments without using real money. It is specially designed for beginners who are new to UPI and want to learn safely.

🔹 Practice sending money  
🔹 Scan QR codes  
🔹 View transaction history  
🔹 Learn fraud prevention  

---

## ✨ Features

- 🔐 OTP-based Login System  
- 💰 Virtual Wallet (Shiksha Coins)  
- 📤 Send & Receive Money (Simulation)  
- 📷 QR Code Scanner (Simulated UPI Payments)  
- 📊 Transaction History  
- 🧠 Quiz Section (Learn UPI Safety)  
- 🌐 Website for APK Download
